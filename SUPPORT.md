# Support

[GitHub Issues](https://github.com/faustbrian/go-http-signature/issues) accepts
reproducible defects, documentation gaps, and bounded feature proposals.
Include the module path and version, Go version, platform, minimal reproduction,
expected behavior, actual behavior, and relevant non-secret logs.

[GitHub Discussions](https://github.com/faustbrian/go-http-signature/discussions)
accepts adoption questions and design exploration. Use the private process in
[`SECURITY.md`](SECURITY.md) for vulnerabilities.

Support covers the published stable-v1 root-module line according to
[`COMPATIBILITY.md`](COMPATIBILITY.md). The current published release is
`v1.0.0`; unreleased main-branch behavior is not a supported release.
